# Design reference

Source: Apple UI - Recreated (figmamarket.com), Apple - 04, node 0:1838.

Original frame: 1440 x 18663 pixels. Product imagery is extracted from the supplied Figma file and bundled locally. Design-era product names, USD prices, and offer text are retained for visual fidelity; these are not current offers. Helvetica Neue uses system fallbacks on systems where it is not installed.

The mobile interface is an original React Native adaptation of the same content. Purchase selection and the bag are local demonstrations; no orders, payments, accounts, or subscriptions are submitted. Links to Apple open the external website.
